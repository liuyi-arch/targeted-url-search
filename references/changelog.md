## v5.0.0 — 可维护性重构

**目标**：将单文件 448 行的 SKILL.md 拆分为模块化结构，实现关注点分离。

### 结构变更

| 变更 | 说明 |
|------|------|
| SKILL.md 精简 | 448 行 → ~130 行，仅保留核心编排逻辑 |
| 新增 `execution-flow.md` | 从 SKILL.md 提取 Step 0-5 详细代码 |
| 新增 `error-handling.md` | 从 SKILL.md 第八节提取错误处理经验 |
| 新增 `changelog.md` | 本文件，记录版本变更 |
| 更新 `README.md` | 修正过时的 v2.0 语法引用，同步新文件结构 |
| 消除重复 | 模式检测、站点适配、报告格式不再在 SKILL.md 和 references/ 各写一遍 |

### 设计原则

- **SKILL.md = 编排层**：告诉 agent "做什么"和"去哪里找细节"
- **references/ = 实现层**：包含"怎么做"的详细代码和规则
- **每个信息只存在于一个地方**：修改时不需要多处同步

## v4.0.0 — 重大技能升级

**目标**：修复浏览器闪退、拼多多漏检、输出格式偏离三个核心问题。

### 核心改进

| 改进 | 说明 |
|------|------|
| browser-use v3.0 语法 | 全部命令改为 `browser-use <<'PY'...PY'` Python pipe 模式 |
| 搜索步骤强制执行 | 不可跳过，解决 SPA 站点默认列表不完整的问题 |
| 空结果直接跳过 | 不尝试兜底策略（URL 参数、分页、滚动加载） |
| 输出格式简化 | 匹配→网站名称+岗位链接；不匹配→网站名称+状态+说明+网站链接 |
| 增强原子模式触发 | 新增"在XX中用XX检索是否有"等模式 |
| 补充拼多多站点适配 | careers.pddglobalhr.com 的搜索框、按钮、提取逻辑 |
| Chrome 远程调试错误处理 | zsh 通配符展开、权限弹窗等经验 |
