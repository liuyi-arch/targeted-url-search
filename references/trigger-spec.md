# 触发规范

本文件定义 `targeted-url-search` 的唯一触发规则、关键词提取规则和补问策略。

## 一、触发模式

| 模式 | 标识 | 触发条件 | URL 来源 |
|------|------|---------|---------|
| 工作流模式 | `workflow` | 用户明确提及 `targeted-url-search` | 上游 JSON 文件 |
| 原子模式 | `atomic` | 用户表达“在某个网站检索某个关键词”的语义 | 用户直接输入 |

冲突处理：

- 若两种模式同时命中，`workflow` 优先
- 若两种模式都未命中，则不触发本技能

## 二、工作流模式触发词

以下字符串出现在用户提示词中时，触发 `workflow`：

- `targeted-url-search`
- `targeted url search`

匹配要求：

- 不区分大小写
- 只要明确提到技能名即可，不要求同时出现关键词

## 三、原子模式语义

以下语义模式触发 `atomic`：

- 在某个网站上搜索某个关键词
- 在某个链接里检索是否有相关岗位
- 打开某个网址后搜索指定关键词
- 帮我看某个招聘链接里有没有某类岗位

推荐判断组合：

1. `URL/网站/链接/网址` + `搜索/检索/找/查` + `岗位/职位/关键词`
2. `打开/进入` + `URL` + `搜索/检索`
3. `在` + `网站/URL` + `用/中/里面` + `检索/搜索` + `关键词`
4. `URL` + `关键词` + `有没有/是否有` + `岗位`

不触发示例：

- `搜索前端岗位`
- `帮我找工作`
- 只给出关键词但没有站点上下文的请求

## 四、输入提取

### URL 提取

正则：

```text
https?://[^\s<>"'，。、）)]+
```

规则：

- 支持多个 URL
- 允许空格、换行、逗号分隔
- 中文标点应视为 URL 终止符

### 关键词提取

优先级：

1. 引号中的内容
2. `搜索/检索/找/查` 后的岗位关键词
3. 常见岗位词库命中

常见岗位词示例：

- 前端
- 后端
- 算法
- 产品
- 测试
- 运维
- 数据
- 安全
- 客户端
- 移动端

### 补充信息提取

补充信息用于推导 `PROJECT_MODE`，具体映射以 `references/input-contract.md` 为准。

### 排除序号提取

仅工作流模式使用，示例：

- `第2个不用查` -> `[2]`
- `排除第1和第3个` -> `[1, 3]`
- `1、3不用` -> `[1, 3]`

## 五、补问策略

### 工作流模式

当缺少关键词，或上游 JSON 未明确可用时，使用 `AskUserQuestion`：

- 问题：`是否对上一个节点输出网站进行全量检索？`
- 选项：
  - `全量检索`：检索全部网站，并补充关键词与补充信息
  - `选择性检索`：排除部分网站，并补充排除序号、关键词与补充信息

后续追问：

- 选择 `全量检索`：`请给出检索关键词和补充信息（可选，如校招/实习）。`
- 选择 `选择性检索`：`请说明哪些网页不需要检索（给出序号）、检索关键词、补充信息（可选）。`

### 原子模式

缺字段时直接提示，必须指出缺的是什么：

- URL 缺失：`未检测到待检索网站网址。请输入待检索网站网址、检索关键词、其余补充信息（可选）。`
- KEYWORD 缺失：`未检测到检索关键词。请输入待检索网站网址、检索关键词、其余补充信息（可选）。`
- 两者都缺失：`请输入待检索网站网址、检索关键词、其余补充信息（可选）。`

## 六、终止条件

补问循环的终止条件只有两个：

- 必填字段校验通过
- 用户明确取消任务
