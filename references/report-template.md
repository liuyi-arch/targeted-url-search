# 报告模板

技能执行完成后，按以下格式生成精炼报告。报告仅包含 4 个部分，不添加冗余信息。

---

## 模板

```markdown
# 招聘岗位筛选结果

## 一、任务参数

| 参数 | 值 |
|------|-----|
| 勾选模式 | {MODE描述} |
| 搜索词 | {KEYWORD} |
| JSON文件 | {文件名} |
| 站点数 | {N} |

## 二、标题含"{KEYWORD}"的岗位

| # | 企业 | 职位标题 | 链接 |
|---|------|---------|------|
| 1 | {企业名} | {职位标题} | {url} |
| ... | ... | ... | ... |

> 共 {N} 个匹配岗位

（如无匹配岗位，显示"无匹配岗位"）

## 三、标题不含"{KEYWORD}"的岗位

| # | 企业 | 职位标题 | 链接 |
|---|------|---------|------|
| 1 | {企业名} | {职位标题} | {url} |
| ... | ... | ... | ... |

> 共 {N} 个非匹配岗位

（如无结果，显示"无结果"）

## 四、注意事项

{站点适配问题}
{错误处理经验}
{供下次执行参考的要点}
```

---

## 示例

以下为使用 模式1(校招) + 搜索词"前端" 时的示例输出：

```markdown
# 招聘岗位筛选结果

## 一、任务参数

| 参数 | 值 |
|------|-----|
| 勾选模式 | 1（校招/全职/正式） |
| 搜索词 | 前端 |
| JSON文件 | smartsheet_filter_result.json |
| 站点数 | 2 |

## 二、标题含"前端"的岗位

无匹配岗位

## 三、标题不含"前端"的岗位

| # | 企业 | 职位标题 | 链接 |
|---|------|---------|------|
| 1 | 合合信息(INTSIG) | 27届校招-AI全栈开发工程师 | https://intsig.zhiye.com/campus/jobs/... |
| 2 | 合合信息(INTSIG) | 27届校招-后端工程师(AI方向) | https://intsig.zhiye.com/campus/jobs/... |
| 3 | 原力灵机(Dexmal) | 【27届校招】软件开发工程师 | https://dexmal-inc.jobs.feishu.cn/.../detail?... |
| 4 | 原力灵机(Dexmal) | 【27届校招】后端开发工程师 | https://dexmal-inc.jobs.feishu.cn/.../detail?... |

> 共 4 个非匹配岗位

## 四、注意事项

1. INTSIG(intsig.zhiye.com): 搜索按钮点击未触发过滤，使用 URL 参数 ?keyword=前端 备选方案。URL 含 /campus/ 即满足模式1，无需额外勾选。
2. 飞书招聘(dexmal-inc.jobs.feishu.cn): 校园招聘复选框使用 .atsx-tree-checkbox 类，搜索功能正常。
3. 两家公司的校招岗位均无"前端"专门岗位，但有"全栈开发工程师"等可能涉及前端工作的岗位。
4. 只检查了第一页结果，未分页加载更多。
```

---

## 格式规则

1. **报告文件名**: `{KEYWORD}岗位筛选结果.md`（如 `前端岗位筛选结果.md`）
2. **保存位置**: 当前工作目录
3. **链接格式**: 完整 URL，不截断
4. **表格顺序**: 按企业分组，同一企业内按职位标题排序
5. **注意事项**: 只记录对下次执行有参考价值的信息，不记录执行过程细节
