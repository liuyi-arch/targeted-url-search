# 站点模式库（Patterns）

> **特例层**：只放 **S 类失败（站点走不通）** 的站点。M 类（方法不足）→ 动作文件加方法，**不进本文件**；单站点经验先进 site-notes.md，同坑 ≥2 次且方法层无法覆盖 → 提升为模式；索引表 = 唯一增长点。

## P1 · 自研站点

**识别**：非常见招聘系统特征。

**应对**：
- 3b：自主最多 3 个导航动作（如联想页面内再点"招聘岗位"二级 Tab；万得介绍页点"2027年校园招聘"标题区块才出职位列表；快手点"27届留用实习招聘"radio 才显示实习岗）。
- 3c：搜索框 iframe 兜底；仍无 → 终止站点，标"搜索框未找到"。
- 3d/3e：`get_job_titles` 判空取 ≤5 标题 → `extract_matched_links` 按 KEYWORD 提取命中/首个职位链接。

**代表站点**：联想 `talent.lenovo.com.cn/campus`、万得 `www.wind.com.cn`、快手 `campus.kuaishou.cn`。

---

## P2 · 登录墙/需登录站点

**识别**：岗位可正常搜索/列表，但岗位详情、投递、"申请"按钮需登录态；或 URL 直达为绑定/内推引导页（需手机验证码）。

**应对**：
- 3b：绑定/引导页（如招商 cmbnt `bindInvited`）→ 点顶部导航"校园招聘/社会招聘"菜单（`.menu-item`）进入职位列表页，列表 `<a>` 链接仍可直接提取（3e 走 extract_a_links）。
- 3e：岗位卡片无详情链接且"申请/查看详情"需登录 → 无法提取岗位详情 URL，**3e 归类 M/S 并在报告"说明"标注"登录墙无法提取链接"**，站点不判失败，结果按搜索命中情况记录。

**坑点**：登录墙是站点权限限制，非方法缺陷；不要反复重试点击，直接标记后进入下一站点。

**代表站点**：网易互娱 `hr.163.com/product.html/game`、招商网络科技 `cmbnt.cmbchina.com/bindInvited`。

---

## P3 · 表单投递页

**识别**：页面为投递表单（字段：姓名/手机/邮箱/学校/学历/专业 + "投递岗位"选择），非职位列表；常见平台 jsj.top（金数据）。

**应对**：
- 3b/3c：跳过搜索框流程——无职位列表、无搜索框，岗位以表单控件呈现（radio `.other-choice-option-name` / select）。
- 3e：枚举表单岗位选项文本，KEYWORD 命中即判定；**无独立岗位详情链接，投递入口即表单 URL**，报告链接填表单 URL。

**坑点**：勿按"职位列表页"逻辑等待岗位容器（wait_jobs 会超时）。

**代表站点**：九坤投资 `jsj.top/f/{formId}?x_field_1=wd`。
